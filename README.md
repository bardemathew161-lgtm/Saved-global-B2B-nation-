## Deploy with Cloudflare Pages

This is a static Cloudflare Pages project. The site is served from the repository root, with no build command and `.` as the output directory.

### Dashboard deployment

1. Push this repository to GitHub.
2. In Cloudflare, open **Workers & Pages** and choose **Create application** > **Pages** > **Connect to Git**.
3. Select this repository and use these build settings:
	- Framework preset: `None`
	- Build command: leave empty
	- Build output directory: `.`
4. Deploy the project. Cloudflare will provide a `pages.dev` URL.

### Wrangler deployment

Install Wrangler, authenticate, and deploy from the repository root:

```bash
npm install -g wrangler
wrangler login
wrangler pages deploy . --project-name saved-global-b2b-nations
```

The `_headers` file adds baseline security headers automatically on Cloudflare Pages.

### Custom domain

In the Pages project, open **Custom domains**, add your domain, and follow Cloudflare's DNS prompts. Do not put API keys or other secrets in this repository.

The AI chat endpoint provides sample guidance. The contact endpoint validates submissions but returns a not-configured response and does not store or deliver them. Connect contact submissions to a database or email service before accepting real requests.

### Local demo login

The login screen includes a local demo account for layout and interaction testing:

- Email: `demo@savedglobal.test`
- Password: `DemoPass123!`

This is not production authentication. Replace the demo login with a hosted authentication provider before launch.
